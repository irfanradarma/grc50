# RSM visual reference

Official website: https://www.rsm.global/indonesia/en

`logo.png` is the unmodified public logo asset from:
https://www.rsm.global/indonesia/profiles/rsm_global_platform/themes/rsm_global_platform_2022/images/logo@2x.png

The presenters, Dena Sucianandika and Teuku Raja Irfan Radarma, represent RSM Indonesia, as confirmed by the user. The deck follows colours and Prelo typography from the RSM Indonesia website and displays the unmodified RSM logo on every slide. Prelo is requested from its original RSM host, with Arial as an offline fallback; proprietary font files are not redistributed. See `docs/topics/ai-audit-and-beyond.md` for the material and `docs/topics/ai-audit-research-notes.md` for research decisions.
